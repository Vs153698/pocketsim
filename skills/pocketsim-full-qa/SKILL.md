# PocketSim Complete QA Suite

Runs the automated 25-step end-to-end verification suite across compatibility, runtime layout, interaction handlers, sensors, network conditioning, permissions, and safe-area compliance.

## Command

```bash
pocketsim qa
```

## Output Artifacts
- Overall execution status (`PASSED` or `FAILED`)
- Compatibility analysis breakdown
- Runtime interaction & form submission verification
- Hardware sensor & network conditioning validation
- Safe-area violation and overflow anomaly detection
- Structured JSON test report
